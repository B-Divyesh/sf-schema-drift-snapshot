Privacy

Effective August 27, 2026

Your database metadata does not go to Schema Drift Snapshot or Sociobot. The CLI runs locally, and the browser demo compares only the text already in your tab.

What the CLI handles

The CLI connects directly to the PostgreSQL or MySQL URL you provide and reads catalog metadata: schema, table, view, column, index, and foreign-key definitions. It does not read row data, retain credentials, send telemetry, or upload snapshots. Snapshot and report files stay wherever you save them.

What the site stores

We use no advertising cookies or behavioral analytics. If you restore or receive a Pro license, the token and its most recent verification verdict are stored in your browser's local storage. You can remove them by clearing site data.

License verification and checkout

The site sends a license token directly to the Sociobot API when it needs verification, at most once per day after a successful check. Buying Pro opens Sociobot's hosted checkout; Sociobot / Dodo acts as merchant of record and processes the purchase under its own payment records. Schema Drift Snapshot never receives card details.

Offline cache

A service worker caches public site files on your device so documentation and the local demo can reopen offline. It contains no schema input. Clear site data to remove the cache.

Your choices

You can use every free feature without a license, payment, account, analytics identifier, or site storage beyond the offline shell. Use --redact-names with a shared secret before sending a snapshot to another person.

Contact

For a privacy request or security report, open a private security advisory on the project repository or contact Sociobot through sociobot.in.
